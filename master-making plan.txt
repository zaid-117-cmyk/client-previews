1. CORE STRATEGY & THE "VALUE-FIRST" FRAMEWORK
================================================================================
Traditional cold outreach fails because it asks for 15-30 minutes of a busy
business owner's time before providing any proof of competence. 


The Value-First Method reverses this dynamic:
1. Email 1 (The Hook): Inform the owner that you noticed specific flaws in their
   current website and already designed a modern, high-converting version for them.
   Ask: "Would you like me to send over the live link?"
2. Email 2 (The Delivery - < 5 min after reply): When they reply "Yes", the AI
   system delivers their customized, live-hosted website preview with a link to
   book a quick 10-minute walkthrough call.
3. The Outcome: High reply rates (20-35%) and warm discovery calls because the
   prospect has already seen tangible proof of your work.

7. PHASE 4: AUTOMATED CI/CD & GITHUB PAGES DEPLOYMENT
================================================================================


Step 1: GitHub Repository Setup
- Create a public GitHub repository named `client-previews`.
- Enable GitHub Pages in Settings -> Pages -> Source: Deploy from Branch (`main` or `gh-pages` / `/previews` folder).


Step 2: Subfolder / Dynamic Branch Previews
- To generate a unique link for each client:
  Option A (Directory-based): Have the Python script create a new directory:
  `/previews/[client-slug]/index.html` with injected `siteConfig.json`.
  Push to GitHub -> Live link is `https://[yourusername].github.io/client-previews/previews/[client-slug]/`
- Option B (Automated GitHub Action):
  A GitHub Action workflow runs on every push, builds the static HTML, and publishes to GitHub Pages in under 60 seconds.
